# ElectroLab 3D

شبیه‌ساز آزمایشگاه الکترونیک سه‌بعدی.

## اجرا

```bash
cd frontend-3d
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

مرورگر: http://127.0.0.1:5173

## قابلیت‌ها

- بردبورد ۳D، سیم‌کشی، کاتالوگ
- AC/DC، R/C/L، دیود، LED، ترانزیستور
- بردهای Arduino / ESP32 / Pico / STM32
- اسیلوسکوپ، مولتی‌متر، MCU C++
- ذخیره پروژه و ذخیره خودکار

https://github.com/mydsoftware/ElectroLab-AI
