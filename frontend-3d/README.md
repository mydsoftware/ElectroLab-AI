# ElectroLab 3D

شبیه‌ساز آزمایشگاه الکترونیک سه‌بعدی.

## اجرا

```bash
cd frontend-3d
npm install
npm run dev
```

## قابلیت‌ها

- بردبورد ۳D، سیم‌کشی، کاتالوگ
- AC/DC، R/C/L، دیود، LED، MCUها
- اسیلوسکوپ + پروب با هایلایت نت
- مولتی‌متر، C++ آردوینو، `.ino`
- یکسوساز پل و آزمایشگاه‌های آماده

## میانبر

W سیم · P پروب · R چرخش · Del حذف
