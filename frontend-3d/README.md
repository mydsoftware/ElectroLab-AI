# ElectroLab 3D

شبیه‌ساز سه‌بعدی آزمایشگاه الکترونیک — بردبورد، سیم‌کشی، نت‌لیست SPICE و تست.

## اجرا

```bash
cd frontend-3d
npm install
npm run dev
```

http://localhost:5173

## قابلیت‌ها

- [x] بردبورد سه‌بعدی
- [x] منبع ۵V، مقاومت، LED
- [x] درگ‌ودراپ + snap
- [x] سیم‌کشی (دو سوراخ)
- [x] نت‌لیست SPICE
- [x] شبیه‌سازی (API یا محلی)
- [x] روشن شدن LED
- [ ] خازن / ترانزیستور / آردوینو
- [ ] ngspice کامل
- [ ] Hardware Agent

## گردش کار

1. منبع ۵V اضافه کنید
2. مقاومت و LED بچینید
3. حالت سیم‌کشی → وصل کنید
4. شبیه‌سازی / تست
