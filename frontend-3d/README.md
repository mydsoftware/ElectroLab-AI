# ElectroLab 3D

شبیه‌ساز سه‌بعدی آزمایشگاه الکترونیک — بردبورد، سیم‌کشی، نت‌لیست SPICE و تست.

## اجرا

```bash
cd frontend-3d
npm install
npm run dev
```

http://localhost:5173

## قابلیت‌ها

- [x] بردبورد سه‌بعدی با سوراخ و ریل
- [x] قطعات: منبع ۵V، مقاومت، LED، خازن
- [x] درگ‌ودراپ + snap
- [x] سیم‌کشی بین سوراخ‌ها
- [x] چرخش ۹۰ درجه قطعه
- [x] ویرایش مقدار مقاومت/خازن
- [x] مدار نمونه آماده
- [x] تولید و دانلود نت‌لیست `.cir`
- [x] شبیه‌سازی (API یا آفلاین) + روشن شدن LED
- [x] میانبرهای صفحه کلید (W / R / Del / Esc)
- [ ] ترانزیستور / آردوینو
- [ ] ngspice با پارس ولتاژ کامل
- [ ] Hardware Agent

## میانبرها

| کلید | عمل |
|------|-----|
| W | حالت سیم‌کشی |
| V یا Esc | حالت انتخاب |
| R | چرخش قطعه |
| Delete | حذف قطعه |

## گردش کار

1. «بارگذاری مدار نمونه» یا قطعات دستی
2. سیم‌کشی
3. شبیه‌سازی / تست
4. دانلود نت‌لیست
