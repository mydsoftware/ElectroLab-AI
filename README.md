# ElectroLab AI

**پلتفرم یکپارچه شبیه‌سازی، تست و اعتبارسنجی بردهای الکترونیکی**

ElectroLab AI با هدف ایجاد یک آزمایشگاه نرم‌افزاری و سخت‌افزاری ساخته می‌شود: طراحی و ثبت پروژه، اجرای شبیه‌سازی، تعریف سناریوهای تست، اتصال کنترل‌شده به تجهیزات واقعی و تولید گزارش قابل ردیابی.

> وضعیت فعلی: نسخه آغازین MVP و زیرساخت توسعه. این نسخه هنوز شبیه‌ساز کامل همه بردها نیست و نتیجه تست نرم‌افزاری را معادل تأیید ایمنی یا عملکرد فیزیکی نمی‌داند.

## قابلیت‌های نسخه آغازین

- API مبتنی بر FastAPI
- فهرست اولیه خانواده‌های برد
- مدل استاندارد سناریوی تست و نتیجه PASS/FAIL
- اعتبارسنجی محدوده اندازه‌گیری با تلورانس
- تشخیص در دسترس بودن موتور ngspice
- نقطه شروع امن برای توسعه Hardware Agent
- تست خودکار و CI با GitHub Actions

## معماری هدف

- **Frontend:** رابط وب React/Next.js (مرحله بعد)
- **Backend:** Python + FastAPI
- **Simulation adapters:** ngspice، Renode، Wokwi و ابزارهای HDL
- **Hardware bridge:** USB، UART، GPIO و SCPI از طریق Agent محلی
- **Data:** PostgreSQL و ذخیره‌سازی فایل پروژه
- **Validation:** قواعد قطعی و قابل تکرار؛ هوش مصنوعی فقط نقش کمکی در تحلیل دارد.

## اجرای محلی

نیازمند Python 3.11 یا بالاتر:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
uvicorn backend.app.main:app --reload
```

سپس:
- API: http://127.0.0.1:8000
- مستندات Swagger: http://127.0.0.1:8000/docs
- سلامت سرویس: http://127.0.0.1:8000/api/v1/health

## اجرای تست‌ها

```bash
pip install -r requirements-dev.txt
pytest
```

## اجرای Docker

```bash
docker compose up --build
```

## اصول ایمنی و اعتبارسنجی

1. تست سخت‌افزار در این نسخه فقط زیرساخت نرم‌افزاری است؛ هیچ خروجی فیزیکی به‌صورت خودکار تحریک نمی‌شود.
2. هر تست باید مقدار مرجع، واحد، حد مجاز و شناسه نسخه مدار/Firmware داشته باشد.
3. PASS فقط به معنی عبور از همان تست تعریف‌شده است، نه تأیید کلی ایمنی یا انطباق محصول.
4. تست برق شهر، ولتاژهای خطرناک و بارهای پرتوان به تجهیزات ایزوله، حفاظت اضافه‌جریان/اضافه‌ولتاژ و طراحی تخصصی نیاز دارد.
5. نتیجه شبیه‌سازی و اندازه‌گیری واقعی باید جداگانه نگهداری شوند.
