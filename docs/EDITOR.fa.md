# راهنمای ویرایشگر گرافیکی مدار

ویرایشگر در GitHub Pages از مسیر `docs/index.html` ارائه می‌شود و به‌صورت مستقل برای طراحی اولیه مدار قابل استفاده است.

## امکانات فعلی

- افزودن مقاومت، خازن، سلف، منبع ولتاژ و منبع جریان
- تغییر شناسه و مقدار هر قطعه
- انتخاب دو ترمینال و ایجاد اتصال سیم با جلوگیری از اتصال تکراری و اتصال دوباره دو ترمینال یک گره
- محاسبه نام گره‌های الکتریکی و نمایش آن‌ها کنار ترمینال‌ها
- اعتبارسنجی مستقل توپولوژی الکتریکی: اتصال کوتاه، پایه آزاد، نبود زمین مرجع، زیرمدار شناور، سیم تکراری یا معیوب، گره انشعاب رهاشده، شناسه/مقدار نامعتبر و منابع ولتاژ ایده‌آل موازی
- تعیین گره زمین (گره صفر)
- تولید خودکار Netlist برای SPICE
- ذخیره خودکار پروژه در حافظه مرورگر
- دریافت Netlist با پسوند `.cir` و خروجی ساختار پروژه با JSON
- ارسال Netlist به API شبیه‌سازی ngspice

## کار با ویرایشگر

1. از نوار ابزار، قطعات را اضافه کنید.
2. برای سیم‌کشی، حالت «اتصال سیم» را انتخاب کنید؛ سپس دو ترمینال را بزنید.
3. حالت «اتصال به زمین» را انتخاب و ترمینال مرجع مدار را مشخص کنید.
4. روی قطعه بزنید و شناسه یا مقدار آن را تغییر دهید.
5. Netlist تولیدشده را بررسی کنید.
6. برای اجرای تحلیل، نشانی Backend را تنظیم و اتصال را بررسی کنید؛ سپس اجرای شبیه‌سازی را بزنید.

## فرمت مقادیر

نمونه‌های قابل استفاده: `1k`، `10u`، `100n`، `4.7k`، `5` و `1m`. در این نسخه مقادیر عددی با پیشوند مهندسی پشتیبانی می‌شوند.

## محدودیت‌ها

نسخه فعلی ابزار ویرایشگر گرافیکی پایه است؛ جابه‌جایی قطعات، چرخش، Undo/Redo، نام‌گذاری گره‌ها، مسیریابی اولیه و اعتبارسنجی توپولوژی الکتریکی پشتیبانی می‌شوند. اعتبارسنجی، خطاها و هشدارهای ساختاری را گزارش می‌کند و جایگزین شبیه‌سازی SPICE یا بررسی مهندسی و ایمنی نیست. کتابخانه نمادهای کامل، تحلیل گذرا، تحلیل AC، مدل MCU و طراحی PCB هنوز پیاده‌سازی نشده‌اند. موتور Backend فعلی فقط زیرمجموعه محدود عناصر R/C/L/V/I و دستور `.op` را می‌پذیرد.

صفحه GitHub Pages صرفاً رابط استاتیک است. برای اجرای شبیه‌سازی باید Backend FastAPI به همراه ngspice اجرا و نشانی API در صفحه وارد شود.


## موتور اعتبارسنجی الکتریکی

موتور مستقل در `docs/validator.js` اجرا می‌شود و موارد زیر را بررسی می‌کند:

- اتصال کوتاه ناشی از قرارگرفتن دو پایه یک قطعه در یک گره
- پایه‌های آزاد و نبود مرجع زمین
- زیرمدارهای شناور که به زمین مرجع متصل نیستند
- شناسه و مقدار نامعتبر یا شناسه تکراری قطعات
- سیم تکراری، سیم با ترمینال ناموجود و سیم با دو سر یکسان
- گره انشعاب بدون اتصال
- اتصال چند منبع ولتاژ ایده‌آل به یک جفت گره موازی

این قواعد، بررسی ساختار مدار هستند؛ صحت عملکرد، پایداری عددی، توان قطعات و ایمنی واقعی را تضمین نمی‌کنند. برای این موارد باید تحلیل مناسب SPICE و بررسی سخت‌افزاری انجام شود.
