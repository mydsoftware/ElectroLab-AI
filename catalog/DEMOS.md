# دموهای آماده

| نام | توضیح |
|-----|--------|
| نمونه DC (LED) | منبع + مقاومت + LED |
| نمونه AC + اسکوپ | فیلتر RC |
| **یکسوساز پل** | AC + ۴ دیود + بار، پروب روی خروجی |
| MCU Blink | Arduino D13 |
| ESP32 | GPIO2 |
| Pico | GP25 |
| STM32 | PC13 |

در حالت پروب، کل **نت بردبورد** هم‌رنگ CH1/CH2 هایلایت می‌شود.
