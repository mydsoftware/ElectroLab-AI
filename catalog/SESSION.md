# ادامه جلسه — ذخیره خودکار و آزمایشگاه MCU

## جدید

- **ذخیره خودکار** در localStorage (بازیابی هنگام باز شدن صفحه)
- دکمه **آزمایشگاه MCU (Blink)**: برد + LED + مقاومت + اجرای اسکچ C++ Blink
- **نقشه پایه‌های Arduino Uno** در پنل MCU
- میانبر **P** برای حالت پروب اسکوپ

## میانبرها

| کلید | کار |
|------|-----|
| W | سیم‌کشی |
| P | پروب |
| R | چرخش |
| Del | حذف |
| Esc | انتخاب |
