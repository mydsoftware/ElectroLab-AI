# نمونه کاربرد قطعات (فارسی)

## ترانزیستورها

| قطعه | کاربرد |
|------|--------|
| 2N2222 / 2N3904 | سوییچ رله و LED؛ تقویت سیگنال ضعیف میکروکنترلر |
| BC547 / BC557 | پروژه‌های آموزشی آردوینو؛ سوییچ بار کوچک |
| TIP120 | درایو موتور و بار جریان بالا با پایه کم |
| IRF540N / IRFZ44N | PWM موتور و نوار LED قدرت |

## آی‌سی‌ها

| قطعه | کاربرد |
|------|--------|
| NE555 | تایمر، پالس، PWM و آژیر بدون MCU |
| LM358 | تقویت سنسور آنالوگ و بافر |
| LM393 | آستانه دیجیتال از سیگنال آنالوگ |
| 74HC595 | زیاد کردن خروجی‌های دیجیتال |
| PC817 | ایزوله کردن قدرت از منطق |

## سنسورها

| قطعه | کاربرد |
|------|--------|
| DHT11/22 | دما و رطوبت گلخانه و خانه |
| DS18B20 | دمای دقیق / ضدآب |
| HC-SR04 | فاصله و مانع‌یابی ربات |
| PIR SR501 | تشخیص حرکت انسان |
| MQ-2 / MQ-135 | گاز، دود و کیفیت هوا |
| MPU6050 | بالانس و زاویه ربات |
| رطوبت خاک | آبیاری هوشمند |

## نمایشگرها

| قطعه | کاربرد |
|------|--------|
| LCD 1602 / 2004 | منو و نمایش متن وضعیت |
| LCD I2C | همان LCD با دو سیم |
| SSD1306 OLED | گجت کم‌مصرف و نمودار کوچک |
| ST7735 / ILI9341 | UI رنگی و داشبورد |
| TM1637 | ساعت و عدد درشت |
| MAX7219 | ماتریس و تابلو روان |
| WS2812 | نور وضعیت RGB |

متن کامل هر قطعه در فیلد `description_fa` داخل `components.json` است.
