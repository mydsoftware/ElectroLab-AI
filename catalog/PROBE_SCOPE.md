# پروب اسیلوسکوپ روی بردبورد

## روش کار

1. مدار را بسازید (مثلاً منبع AC + مقاومت + خازن)
2. حالت **پروب اسکوپ** را از نوار ابزار بزنید
3. روی یک **حفره** کلیک کنید → **CH1** (آبی)
4. روی حفره دوم کلیک کنید → **CH2** (صورتی)
5. **شبیه‌سازی** را بزنید
6. پنل اسیلوسکوپ شکل‌موج همان گره‌ها را نشان می‌دهد

## نکات

- مخروط رنگی روی حفرهٔ پروب‌شده دیده می‌شود
- از پنل اسکوپ می‌توان CH1/CH2 را دوباره انتخاب یا پاک کرد
- اگر پروب نگذارید، گره‌های پیش‌فرض + منبع نمایش داده می‌شوند
