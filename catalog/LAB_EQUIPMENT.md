# تجهیزات آزمایشگاه ElectroLab

## ابزارهای اندازه‌گیری و منبع

| شناسه | نام | کاربرد |
|------|-----|--------|
| lab-oscilloscope-2ch | اسیلوسکوپ دو کاناله | شکل موج، فرکانس، دامنه |
| lab-multimeter | مولتی‌متر دیجیتال | V / A / R / پیوستگی |
| lab-function-generator | فانکشن ژنراتور | سینوسی / مربعی / مثلثی |
| lab-bench-psu | منبع تغذیه رومیزی | ولتاژ و جریان قابل تنظیم |
| lab-logic-analyzer | تحلیل‌گر منطقی | UART / SPI / I2C |
| lab-lcr-meter | LCR متر | R / C / L دقیق |
| lab-frequency-counter | فرکانس‌شمار | اندازه‌گیری فرکانس |
| lab-soldering-station | ایستگاه لحیم | ساخت واقعی |
| lab-probe-scope | پروب اسیلوسکوپ | اتصال تست |
| lab-breadboard-830 | بردبورد ۸۳۰ | نمونه‌سازی |

در فرانت ۳D از کاتالوگ → دسته «تجهیزات آزمایشگاه» → افزودن به صحنه.

مدل‌های ۳D: Oscilloscope, Multimeter, FunctionGenerator, BenchPSU, LabInstrument.
