# شبیه‌ساز MCU — به‌روز

## قابلیت‌ها

- اسکچ‌های آماده: Blink، PWM، شمارنده، نور متحرک، چراغ راهنمایی، **دکمه→LED**
- **ویرایشگر اسکچ سفارشی** با `pinMode / digitalWrite / digitalRead / analogWrite / millis / log`
- قطعه **دکمه** روی بردبورد (پایه ورودی + فشار از UI)
- LED با شماره پایه از خروجی MCU روشن می‌شود

## مسیر تست دکمه

1. دکمه بگذار → پایه MCU = 2
2. LED بگذار → پایه = 13
3. اسکچ «دکمه → LED» را اجرا کن
4. دکمه را از پنل ابزار فشار بده → LED روشن می‌شود

## اسکچ سفارشی نمونه

```
pinMode(13, 'output');
digitalWrite(13, Math.floor(millis() / 400) % 2);
```
